# Облачная среда для проверки исходников

На Debian 13 amd64 из корня существующего checkout:

```sh
bash tools/setup-cloud.sh
```

Скрипт загружает OpenJDK 21 из подписанных репозиториев Debian и распаковывает
его в `/workspace/setup-h96max`, без системной установки и sudo. Нужны Bash,
Python 3, Git, APT, dpkg-deb, Debian archive keyring, ffprobe и доступ к
`deb.debian.org`, `security.debian.org`. TLS и проверка подписей APT сохраняются.
Повторный запуск обновляет локальный JDK и повторяет проверки.

После установки в каждом новом shell:

```sh
export PATH=/workspace/setup-h96max/jdk/usr/lib/jvm/java-21-openjdk-amd64/bin:$PATH
```

Скрипт запускает полный unittest-набор, проверки синтаксиса Shell, JSON,
`git diff --check` и анализ журнала тестов. Журнал и отчёт находятся в
`/tmp/h96max-tests.log` и `/tmp/h96max-test-analysis.md`; они не входят в Git.
При ошибке тестов подробности доступны в журнале. Сервисы для этого сценария
не требуются. Каждая облачная задача уже изолирована: использовать существующий
checkout, не создавать worktree без явной просьбы пользователя.

Это подготовка для разработки исходников. Для сборки APK и прошивки отдельно
нужны Android SDK (`tools/setup-sdk.sh`), приватные входы, перечисленные в
`tools/package-ci-inputs.sh`, и прежние ключи подписи из `secrets/`.
Не генерировать замену ключам и не добавлять приватные входы в Git.
Успешные локальные тесты не подтверждают сборку или аппаратную приёмку прошивки.
Скрипт не устанавливает прошивку и не включает swap.

В настройках облачной среды для повторяемой установки можно сохранить команду
`cd /workspace/h96max && bash tools/setup-cloud.sh`; в инструкции старта —
активацию PATH выше и чтение `AGENTS.md`. Публикация среды выполняется отдельно
от коммита в Git.
