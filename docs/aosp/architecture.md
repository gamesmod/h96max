# Android 12 reconstruction architecture
- Source-built framework, ART, APEX, system services and TV-oriented product; use stock ABI and Android API/VNDK as evidence, not generic emulator/GSI product.
- RKR12 common [device.mk](https://github.com/TinkerBoard-Android/rockchip-android-device-rockchip-rksdk/blob/ca9cd2d3577fa9f80187b75558f06fa32e353b3e/device.mk) contains box vs atv product selection and RKR12 property. Use as reference only: do not import GMS, OEM preinstall, tablet packages, permissive settings or unrelated HAL. Common BoardConfig's ARM and gralloc defaults do not prove H96 configuration.
- Radxa RKR12 (1082 project elements) and RKR14 (1084) base manifests explicitly reference RK3588 and Utgard gralloc source; kernel-4.19 linkfiles do not prove kernel availability or compatibility. Neither has a verified RK3328 product. Tags are not full pinned manifest locks.
- VINTF: inventory both system and vendor matrices, ODM, fragments, FCM target level, SKU variants. Static comparison only; run host checkvintf against complete partition trees and kernel/config. No matrix relaxation to force a pass.
- ELF: compare DT_NEEDED, class, symbols, SONAME, linker namespaces and VNDK. A matching library filename is not ABI evidence. Treat GPU, HWC, allocator/mapper, RGA and MPP as a coupled stack.
- First candidate retains known boot/DT/loader/trust and partition schema. Verify AVB chain and existing OTA trust before packaging. No guesses about partition sizes or fstab.
- Applications: current APPS.MD is authoritative, including third-party launcher, stock shared-UID file manager, own APK and tvboxd/bootscreen JARs. Shared UID / privileged permissions require signing and policy review. SmartTube is requested for new contour but not present in current APPS.MD list; record as integration requirement, do not silently change existing release allowlist.
- No speculative product makefiles until stock build props, VINTF, ABI, boot header and partition layout are collected; existing AOSP reference is not a production product.
