# Panadonik 0.4.0 — dev prerelease

Предварительная сборка для H96 Max RK3318 на Android 12, внутренняя память eMMC. Не считать стабильным выпуском.

## Изменения

- IPTV-список объединяет категории в один список, приводит названия к русскому языку и ставит категорию «Для взрослых» первой. Локальная проверка источников прошла, но доступность всех каналов с приставки ещё не подтверждена.
- В плитке «Установка» остаётся Obtainium; версии APK Panadonik следуют версии прошивки.
- Подготовлена установка/обновление eMMC одним подписанным OTA и отдельный комплект чистой установки.

## Известные ограничения

- Алиса AI в образ не включена; голосовая интеграция не готова.
- Целевой прибор пока работает на 0.3.9, поэтому этот кандидат не прошёл горячую проверку на приставке. QR, Wi‑Fi/Ethernet, торрент, графика и время загрузки для 0.4.0 не подтверждены.
- В журнале 0.3.9 обнаружены повторяющиеся VLC/MediaCodec, Fontconfig и графические сообщения, а также буферные задержки аудио. Влияние на плавность требует проверки.
- Security-review не входит в gate dev-релиза. В текущей 0.3.9 подтверждены незащищённый сетевой ADB и permissive SELinux; исправления кандидата на устройстве не подтверждены.
- Установка OTA очищает пользовательские данные. Сохраните необходимые данные заранее.

Используйте эту сборку для тестирования только на совместимой синей ревизии платы. Оставляйте обратную связь с очищенным журналом и точным результатом проверки.
