Обновление Panadonik 0.4.0 для Android 12 / eMMC.

- OTA и отдельные APK приложений проекта публикуются в GitHub Releases; после перехода обновления доступны в приложении «Установка».
- Obtainium регистрирует семь APK Panadonik; версия каждого APK следует версии прошивки.
- Подготовлена раскладка кнопки голосового USB-пульта для Алисы и выдача разрешения микрофона после установки. Алиса не включена в образ; её установка и вызов на приставке ещё не подтверждены. RuStore в образ не входит.
- Категории IPTV нормализованы на русский язык; региональные группы получают флаги страны, категория «Для взрослых» идёт первой, дубли качества объединяются.
- IPTV-списки включают проверенные открытые русскоязычные источники и категорию 18+ в общем плейлисте; в текущей проверке после фильтрации осталось 3 426 каналов, в том числе 183 канала 18+.
- Исправлено отображение и повторное индексирование категорий IPTV после обновления приложения.
- Обновлены документация по аппаратной ревизии, Wi-Fi/Bluetooth, vendor-образу и удалённым OEM-службам.
- Образ для SD не выпускается. Установка OTA с карты выполняется штатным Android 12 recovery.

Перед установкой проверьте, что устройство работает на Android 12 и обновление предназначено для внутренней памяти eMMC.
