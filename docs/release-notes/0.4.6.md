# Panadonik 0.4.6 — подготовка dev-кандидата

## Изменения

- Исправлены штатные команды DDR boost/recover: Android init обращается к реальному system_monitor вместо конечной символьной ссылки, которая вызывала ELOOP. Восстановлена SELinux-метка init-файла. Права реального DDR-атрибута ограничены штатными mediacodec:system 0660. Горячая проверка выполнена на 0.4.5; исполнение новых команд при загрузке ещё не проверено. Ранние ошибки статистики devfreq не объявлены устранёнными.
- В код добавлено приватное сохранение Wi-Fi и авторизованных ключей ADB перед OTA с очисткой. Повторное восстановление продолжает прерванную операцию, не заменяя изменённые пользователем данные. По умолчанию сетевой ADB не включается; восстановление заранее заданного доверенного хоста ограничивается IPv4/IPv6-фильтрами. Полный цикл с целевым recovery ещё требует аппаратной проверки.
- Восстановлены обязательные сторонние приложения; сборка останавливается при неполном комплекте. В Obtainium настраиваются только сторонние APK образа, включая сам Obtainium; собственные org.tvbox.* обновляются с прошивкой.
- Сокращён состав штатных приложений; одна политика удаления используется для конечного образа и очищенных приватных входов CI.
- Экран журнала загрузки запускается после готовности APEX; исправлено отображение температуры.
- Сжатая подкачка отключена. Настройка в приложении удалена, команда включения отклоняется.
- Обновление поддерживает прямой путь GitHub Release по тегу.
- Дополнены источники и проверки IPTV. Актуальное воспроизведение и измеренное качество потоков требуют проверки для нового кандидата.

## Ограничения перед выпуском

Это описание кандидата, не подтверждение аппаратной приёмки. На 2026-11-22 приставка не обнаружена через ADB или USB; установленный артефакт и сохранность горячих изменений сейчас не проверены. Предстоят проверка загрузки до управляемого пультом рабочего стола, обоих сценариев подключения, восстановления Wi-Fi/ADB после очистки, регуляторного региона Wi-Fi и Bluetooth. Требуемый QR-сценарий — добавление торрента в TorrServer с телефона и кнопка «Смотреть на ТВ» — ещё не принят; отдельное удалённое управление VLC не входит в требования.

Остаются разбор ранних ошибок ядра/devfreq, причина прежней паники, функциональные проверки IPTV, пульта, торрента и фильма без лагов, графический стресс-тест, анализ журналов, безопасности и трафика в контролируемой сети. Ключи подписи сохранены прежними; учётные данные Wi-Fi и приватные журналы не включаются в публичные артефакты. Ни dev-, ни стабильный выпуск пока не прошёл аппаратную приёмку.

Установка OTA с очисткой требует отдельного подтверждения после перечисления удаляемых данных: пользовательских приложений, настроек и файлов внутреннего хранилища. Публикация выпуска требует отдельного подтверждения после представления артефактов и результатов приёмки.
