# Panadonik 0.4.6 — подготовка dev-кандидата

## Изменения

- Восстановлены внешние приложения и добавлена обязательная проверка их наличия при сборке. Исправлена сверка плиток после установки.
- Восстановлено подключение Wi‑Fi на проверенной приставке с использованием WPA2 и firmware от её штатной A9. В проекте оставлены прежние файлы совместимости BCM4334.
- Экран журнала загрузки запускается после готовности APEX; исправлено отображение температуры.
- Сжатая подкачка отключена по требованию пользователя. Настройка в приложении убрана, команда включения отклоняется.
- Обновление поддерживает прямой путь GitHub Release по тегу; QR VLC использует HTTPS.
- Дополнены источники IPTV, исследование и проверки; доступность всех новых потоков и минимум 20 каналов для взрослых ещё требуют подтверждения.

## Ограничения перед выпуском

Это рабочее описание кандидата, не подтверждение аппаратной приёмки. Изменение параметра региона Wi‑Fi в сборке ещё не проверено на приставке. Остаются анализ причины прежней паники ядра, проверка времени загрузки, QR с телефона, IPTV и пульта, длительного воспроизведения торрента и графического стресс-теста. Нужны полный анализ журналов и проверка сетевого трафика в контролируемой сети. Приватные входные данные CI и ключи подписи должны быть доступны Actions; учётные данные Wi‑Fi в образ не включаются.

Установка OTA с очисткой требует отдельного подтверждения в интерфейсе. После очистки удаляются приложения пользователя, их настройки и файлы во внутреннем пользовательском хранилище.
