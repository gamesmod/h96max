## Panadonik для H96 Max — Android 12 на eMMC

Panadonik — доработанная система на базе стокового Android 12 для проверенной синей ревизии H96 Max. Интерфейс рассчитан на телевизор: отключены оконные анимации, HDMI ограничен режимом 1920×1080, плитки можно свободно переставлять.

### Что добавлено

- Живой журнал загрузки со сведениями о процессоре, графике, памяти и температуре.
- Общий IPTV-плейлист: категории объединены на русском языке, детские каналы исключены, качество принимается только после измерения от 1080 строк; категория 18+ стоит первой.
- TorrServe и VLC с QR-переходом к удалённому интерфейсу и запуском VLC с приставки.
- Плитки установки, обновления приложений, производительности и управления питанием; Obtainium доступен внутри «Установка».
- Чистая установка eMMC-образа со стоковой системы через Rockchip Loader, дальнейшее OTA-обновление из GitHub Releases.

Сеть Wi-Fi и Bluetooth настроена для проверенной платы с Broadcom BCM4334. Настройки сети сохраняются по выбору пользователя, MAC-адрес не рандомизируется; пароли Wi-Fi в публичный образ не включаются. Для других ревизий платы совместимость не подтверждена.

**Важно:** это описание функций, предусмотренных проектом. Перед публикацией заменить его только на сведения, подтверждённые итоговой сборкой и аппаратными тестами.
