# Чистая установка Panadonik на eMMC

Инструкция для H96 Max RK3318 с проверенной синей платой. Этот способ полностью перезаписывает eMMC и удаляет приложения, сетевые настройки и пользовательские файлы. Перед началом сохраните нужные данные. Для обычного обновления установленной Panadonik используйте подписанный OTA.

## Комплект

В GitHub Release скачайте `Panadonik-ВЕРСИЯ-emmc-clean-install.zip`, `.sha256`, `.sig` и `Panadonik-ВЕРСИЯ-ota-cert.pem`. Сертификат содержит только открытый ключ проекта. Сначала проверьте подпись и контрольную сумму:

```sh
sha256sum -c Panadonik-ВЕРСИЯ-emmc-clean-install.zip.sha256
openssl x509 -in Panadonik-ВЕРСИЯ-ota-cert.pem -pubkey -noout > /tmp/panadonik-ota-public-key.pem
openssl dgst -sha256 -verify /tmp/panadonik-ota-public-key.pem \
  -signature Panadonik-ВЕРСИЯ-emmc-clean-install.zip.sig \
  Panadonik-ВЕРСИЯ-emmc-clean-install.zip
unzip Panadonik-ВЕРСИЯ-emmc-clean-install.zip
cd release/ВЕРСИЯ/emmc
sha256sum --check SHA256SUMS
cd ../../..
```

Понадобится Linux, Python 3 и библиотека libusb. Например, на Ubuntu:

```sh
sudo apt-get install python3 libusb-1.0-0
```

## Запись

1. Выключите приставку. Подключите кабель USB-A–USB-A к OTG/USB 2.0 порту приставки и компьютеру.
2. Переведите приставку в Rockchip Loader. Если ADB уже доступен, используйте `adb reboot loader`; со стоковой системы без ADB используйте recovery-кнопку/отверстие AV согласно аппаратной ревизии.
3. Убедитесь, что хост видит Rockchip Loader (USB `2207:320c`), затем из корня распакованного архива запустите:

   ```sh
   sudo python3 -I tools/rkusb.py flash release/ВЕРСИЯ/emmc
   ```

4. Не отключайте кабель и питание, пока скрипт не закончит запись. Затем перезапустите приставку и дождитесь первичной загрузки.

Записыватель сверяет MD5 каждого исходного региона с манифестом. Ограничение загрузчика этой платы не позволяет надёжно прочитать обратно области выше 32 МиБ в режиме Loader; поэтому успешная запись сама по себе не доказывает полное побайтное совпадение eMMC. Не отключайте питание при ошибке и сохраните текст результата для диагностики.

Эта процедура относится только к указанной модели/ревизии и рассчитанной разметке. Не используйте комплект на другой приставке или ревизии без проверки платы и размера eMMC.
