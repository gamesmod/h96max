# База знаний по отладке Panadonik

## IPTV: HLS без поля RESOLUTION

- Симптом: проверка плейлиста пропускала HLS-потоки без метки разрешения, даже если в них могло быть видео 1080p.
- Причина: генератор отбрасывал варианты HLS без поля `RESOLUTION` до проверки видеосегмента.
- Исправление: для таких плейлистов выбирается вариант по битрейту и измеряется разрешение его видеосегмента через ffprobe. Требование 1080p сохраняется. Исправление вошло в master в коммите `135f417`.
- Проверка: тест воспроизводит отсутствие поля `RESOLUTION` и проверяет обращение к видеосегменту. Плейлист из OTA 0.4.11 прошёл проверку на компьютере сборки. Плавность на приставке проверяется отдельно.
