# Кандидат 0.4.11 — заготовка, 2026-11-23

Статус: подготовка локального кандидата после опубликованного `dev-v0.4.10`. Сборка и
проверки артефакта заполняются после `tools/build-release.sh`. Установка на приставку,
wipe и публикация тега/Release **не выполнялись** и требуют отдельных подтверждений.

## Артефакт

- OTA: `tvbox-update-0.4.11-emmc.zip` — SHA-256 заполнить после сборки.
- Источник сборки: локальный `tools/build-release.sh` на hpprobuntu.
- Каталог `release/0.4.10` не удалялся.

## Проверки (ожидаемые после сборки)

- Сканер Wi‑Fi credentials на финальных ext4 system/vendor.
- `sha256sum --check` в `release/updates/emmc`.
- CMS-подпись прежним OTA-сертификатом.
- Локальные автотесты исходников (не замена аппаратной приёмки).

## Блокеры / пробелы

- Аппаратная приёмка на установленном 0.4.11 не начата.
- На 0.4.10 повторно подтверждены ошибки USB init, а сохранённый снимок старта содержит ошибки devfreq DMC и GPU. Подробности в [разборе загрузки](boot-audit-2026-11-23-followup.md). Это не проверка кандидата 0.4.11.
- `pass` с 0.4.10 не переносится на этот артефакт.
- Тег Release / GitHub prerelease не создавался в рамках этой задачи.
