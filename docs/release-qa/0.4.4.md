## Проверки, ожидающие приставку

В OTA входят только разделы `super`, `boot`, `dtbo`, `vbmeta` и `recovery`; раздела `userdata` нет. Старый `tvboxd` на установленной 0.3.9 отказал в режиме `keep`, поэтому обновление через него не запускалось. Для продолжения был временно запущен собранный кандидатный `tvboxd` из `/data/local/tmp`, без замены системного файла. OTA повторно проверен встроенным recovery-верификатором (`VERIFY OK`), SHA-256 на приставке совпал. Команда `UPDATE_INSTALL … keep` завершилась `DONE ok`; wipe-флаг отсутствовал. После перехода через recovery устройство вернулось в сеть, но защищённый ADB показывает `unauthorized`; системную версию и завершение установки пока нельзя прочитать.

Не подтверждены холодная загрузка, работа полного набора функций, IPTV с видимой картинкой, торрент, графическая нагрузка, кнопки USB-пульта, сеть после загрузки, анализ журналов и свежий сетевой захват. Текущий release gate не пройден. Выбор `keep` не запрашивает очистку данных; режим `wipe` не запускался.

GitHub Release или тег для этого кандидата не создавались.
