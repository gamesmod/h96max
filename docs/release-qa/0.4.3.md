## Живая диагностика IPTV

- На приставке пользовательская отладка IPTV включена; APK 0.4.2 установлен без очистки данных, пользовательский плейлист сохранён.
- Исходный HDMI Auto выдавал 3840×2160p30 при UI 1920×1080. После временного задания полного Rockchip timing и перезагрузки DRM подтвердил 1920×1080p60. Это реальный дефект вывода; такое же значение закреплено в раннем init 0.4.3.
- После переключения режима тот же взрослый поток EPG 7741 продолжал доходить до VLC PLAYING, но видеодекодер и видеоплоскость не появлялись. Значит, неверный HDMI-режим не был единственной причиной. Нужна дальнейшая диагностика VLC/HLS/HEVC; видимое изображение и плавность не подтверждены.
- Установлены `log.tag.VLC`, `persist.log.tag.VLC`, `log.tag.libvlc` и `persist.log.tag.libvlc` в SILENT. Проверен повторный запуск: app-level журнал содержит EPG ID и handoff без URL, VLC URL-строк не появилось.
- После перезагрузки debug flag сохранился. На приставке оставлен HDMI режим 1920×1080p60.
