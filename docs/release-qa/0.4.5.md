## Политика очистки и статус устройства

Обновление через плитку «Установка» теперь выполняется только в режиме `wipe`. Экран предупреждает об удалении приложений, настроек, торрентов и пользовательских файлов; продолжение требует двух явных подтверждений. `tvboxd` отклоняет режим `keep` и команды без `wipe`. Установка 0.4.5 на приставку не запускалась: такая установка удалит данные и ожидает отдельного явного согласия пользователя.

На горячей системе 0.4.4 проверена плитка обновлений с новым APK «Установка» и собранным `tvboxd.jar`: список обнаружил 0.4.5, полное описание выпуска прокручивается, а «Продолжить с очисткой» и «Отмена» остаются видимыми. Этот smoke-тест не запускал OTA и не очищал данные. Полный образ 0.4.5 пока на приставку не установлен.

Кандидатная ветка `candidate/0.4.5` повторно запущена на актуальном коммите: [GitHub Actions run 42862278182](https://github.com/gamesmod/h96max/actions/runs/42862278182) остановился на preflight `Preflight required Actions secrets`. Предыдущие запуски 42860787222 и 42603578142 остановились там же. В README перечислены требуемые секреты; их значения и ключи подписи в чат не передавались. ### Проверка IPTV-передачи в VLC (2026-11-10)

APK IPTV 0.4.5 был установлен поверх приложения на приставке без очистки данных; подпись проверена. VLC открыл M3U выбранной категории и воспроизводил поток, в медиасессии была очередь из 7 каналов. Теперь этот APK включён в пересобранный OTA/clean-install пакет; полная система 0.4.5 на приставке не установлена. ADB-события не заменяют физическую проверку PAGE вверх/вниз на комплектном USB-пульте. Видимая картинка, отсутствие пропусков кадров, остальные функции и анализ сетевого трафика не приняты. Сборочный журнал отдельно показал `SELinux permissive` в конфигурации образа; это открытый риск, требующий оценки и раскрытия в release notes. Общий release gate остаётся закрытым.
