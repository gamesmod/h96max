## Политика очистки и статус устройства

Обновление через плитку «Установка» выполняется только в режиме `wipe`. Экран предупреждает об удалении приложений, настроек, торрентов и пользовательских файлов; продолжение требует двух подтверждений. Пользователь подтвердил очистку непосредственно в интерфейсе. В журнале `tvboxd` зарегистрирована команда `UPDATE_INSTALL ... wipe`; первая попытка завершилась из-за выключенного HTTP-сервера, затем сервер перезапущен, OTA скачан, checksum и подпись проверены, recovery подготовлен к установке.

Пользователь сообщил, что после recovery видел экран установки, затем логотип, а потом рабочий стол. Это подтверждает загрузку интерфейса после процедуры OTA, но системная версия через ADB не прочитана: после очистки устройство не обнаруживается по сети. Пользователь подключил USB A-to-A, но `adb devices` пуст, `lsusb` не показывает новое устройство, а `rkdeveloptool ld` не нашёл приставку в Rockchip Loader. Пользователь сообщил, что приставка работает только через Wi-Fi. Не считать версию 0.4.5 независимо подтверждённой и не считать запуск рабочего стола полной аппаратной приёмкой.

Кандидатная ветка `candidate/0.4.5` повторно запущена на актуальном коммите: [GitHub Actions run 42862278182](https://github.com/gamesmod/h96max/actions/runs/42862278182) остановился на preflight `Preflight required Actions secrets`. Предыдущие запуски 42860787222 и 42603578142 остановились там же. В README перечислены требуемые секреты; их значения и ключи подписи в чат не передавались. Для `RELEASE_INPUTS_ARCHIVE_URL` и `RELEASE_INPUTS_SHA256` локально сформирован приватный архив `/tmp/panadonik-release-inputs.tar.zst` размером 2 836 745 981 байт, SHA-256 `da59585c45c5a86d3d035b05c6c2c086440403ad244534bcd7753f26f18f34ab`; в нём нет ключей подписи. CI на `master` прошёл: [run 42862270740](https://github.com/gamesmod/h96max/actions/runs/42862270740).

До OTA приставка работала на версии 0.4.4; тогда `sys.boot_completed=1`, `/proc/swaps` был пуст, а в доступном буфере logcat не обнаружены warning/error/fatal. После OTA пользователь подтвердил появление рабочего стола; ADB сейчас не видит устройство, поэтому версия, swap, журналы и время загрузки после обновления не измерены. Release gate не пройден. Dev-релиз, тег и GitHub Release не создавались.

Дополнительный read-only монитор 2026-11-10: в последних 1200 записях `logcat` уровня E записей не найдено; температура 63.8 °C, доступно 2935 МиБ из 3949 МиБ RAM. `/vendor` заполнен на 98%. На текущей системе 0.4.4 включены `ro.debuggable=1` и ADB TCP на порту 5555; SELinux в `Permissive`, найдена команда `su`, при этом `ro.adb.secure=1`. Это серьёзные риски текущего устройства; сетевой захват не проводился, конфигурацию не менял.

### Проверка IPTV-передачи в VLC (2026-11-10)

APK IPTV 0.4.5 был установлен поверх приложения на приставке без очистки данных; подпись проверена. VLC открыл M3U выбранной категории и воспроизводил поток, в медиасессии была очередь из 7 каналов. Этот APK включён в пересобранный OTA/clean-install пакет; после процедуры OTA пользователь сообщил о рабочем столе, но версия полной системы 0.4.5 не подтверждена через ADB. ADB-события не заменяют физическую проверку PAGE вверх/вниз на комплектном USB-пульте. Видимая картинка, отсутствие пропусков кадров, остальные функции и анализ сетевого трафика не приняты. Сборочный журнал отдельно показал `SELinux permissive` в конфигурации образа; это открытый риск, требующий оценки и раскрытия в release notes. Общий release gate остаётся закрытым.
