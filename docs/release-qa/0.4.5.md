## Политика очистки и статус устройства

Обновление через плитку «Установка» теперь выполняется только в режиме `wipe`. Экран предупреждает об удалении приложений, настроек, торрентов и пользовательских файлов; продолжение требует двух явных подтверждений. `tvboxd` отклоняет режим `keep` и команды без `wipe`. Установка 0.4.5 на приставку не запускалась: такая установка удалит данные и ожидает отдельного явного согласия пользователя.

Кандидатная ветка `candidate/0.4.5` запустила [GitHub Actions run 42603578142](https://github.com/gamesmod/h96max/actions/runs/42603578142), который остановился на preflight: обязательные Actions secrets не настроены. В README перечислены имена требуемых секретов; их значения и ключи подписи в чат не передавались. Для подготовки `RELEASE_INPUTS_ARCHIVE_URL` и `RELEASE_INPUTS_SHA256` локально сформирован приватный архив `/tmp/panadonik-release-inputs.tar.zst` размером 2 836 745 981 байт, SHA-256 `da59585c45c5a86d3d035b05c6c2c086440403ad244534bcd7753f26f18f34ab`; в нём нет ключей подписи.

При повторной проверке 2026-11-10 удалось подключить ADB к живой системе: подтверждены версия 0.4.4, Android 12, `sys.boot_completed=1`, uptime 103 263 секунды и пустой `/proc/swaps`. В последних 3000 строках доступных буферов logcat не найдено warning/error/fatal записей; короткие кольцевые буферы не покрывают предыдущую загрузку. Для кандидата 0.4.5 не пройдены аппаратные проверки загрузки, сети, QR, IPTV с видимой картинкой, торрента, графики, USB-пульта и сетевого трафика. Установка не запускалась: она очищает пользовательские данные и требует отдельного явного согласия. Release gate не пройден. Dev-релиз, тег и GitHub Release не создавались.

### Проверка IPTV-передачи в VLC (2026-11-10)

Собранный APK IPTV 0.4.5 установлен поверх приложения на приставке с Android 12 без очистки данных. Подпись APK проверена; VLC открыл переданный M3U текущей категории и воспроизводил поток, в медиасессии отображалась очередь из 7 каналов. Автотесты репозитория: 51 успешно. Синтетические ADB keyevents не подтвердили надёжно переключение PAGE вверх и вниз реальным USB-пультом; аппаратная проверка кнопок остаётся незавершённой. Изменение APK пока не включено в зафиксированный OTA/clean-install пакет 0.4.5: пакет необходимо пересобрать из этого исходного кода. Отдельная проверка сетевого трафика во время IPTV-проигрывания не выполнялась, поэтому общий release gate остаётся закрытым.
