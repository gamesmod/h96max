## Политика очистки и статус устройства

Обновление через плитку «Установка» теперь выполняется только в режиме `wipe`. Экран предупреждает об удалении приложений, настроек, торрентов и пользовательских файлов; продолжение требует двух явных подтверждений. `tvboxd` отклоняет режим `keep` и команды без `wipe`. Установка 0.4.5 на приставку не запускалась: такая установка удалит данные и ожидает отдельного явного согласия пользователя.

Кандидатная ветка `candidate/0.4.5` запустила [GitHub Actions run 42603578142](https://github.com/gamesmod/h96max/actions/runs/42603578142), который остановился на preflight: обязательные Actions secrets не настроены. В README перечислены имена требуемых секретов; их значения и ключи подписи в чат не передавались. Для подготовки `RELEASE_INPUTS_ARCHIVE_URL` и `RELEASE_INPUTS_SHA256` локально сформирован приватный архив `/tmp/panadonik-release-inputs.tar.zst` размером 2 836 745 981 байт, SHA-256 `da59585c45c5a86d3d035b05c6c2c086440403ad244534bcd7753f26f18f34ab`; в нём нет ключей подписи. CI на обновлённом `master` прошёл: [run 42845670026](https://github.com/gamesmod/h96max/actions/runs/42845670026).

При повторной проверке 2026-11-10 ADB доступен; приставка сообщает версию системы 0.4.4, Android 12, `sys.boot_completed=1`, uptime около 106 204 секунд и пустой `/proc/swaps`. В последних 2000 строках logcat не обнаружены warning/error/fatal записи; кольцевой буфер не покрывает предыдущую загрузку. OTA 0.4.5 не устанавливался: он очищает приложения, настройки, торренты и пользовательские файлы; отдельное согласие на очистку не получено. Release gate не пройден. Dev-релиз, тег и GitHub Release не создавались.

### Проверка IPTV-передачи в VLC (2026-11-10)

APK IPTV 0.4.5 был установлен поверх приложения на приставке без очистки данных; подпись проверена. VLC открыл M3U выбранной категории и воспроизводил поток, в медиасессии была очередь из 7 каналов. Теперь этот APK включён в пересобранный OTA/clean-install пакет; полная система 0.4.5 на приставке не установлена. ADB-события не заменяют физическую проверку PAGE вверх/вниз на комплектном USB-пульте. Видимая картинка, отсутствие пропусков кадров, остальные функции и анализ сетевого трафика не приняты. Сборочный журнал отдельно показал `SELinux permissive` в конфигурации образа; это открытый риск, требующий оценки и раскрытия в release notes. Общий release gate остаётся закрытым.
