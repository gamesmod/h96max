# Project instructions

- Общение по-русски.
- На компьютере сборки запрещена дисковая подкачка: никогда не создавать и не включать swap-файлы или swap-разделы. Пользователь явно запретил дисковый swap навсегда (2026-11-05). /swap.img удалён; его запись в /etc/fstab отключена; swap.img.swap замаскирован.
- Не использовать zRAM writeback на накопитель. Сжатая память только в ОЗУ допустима по отдельным настройкам пользователя; это не разрешение включать дисковую подкачку.
- Сохранять прежние ключи подписи APK и OTA; не генерировать замену для обновления установленной системы.
- Не публиковать образы, содержащие Wi-Fi credentials. Секреты не выводить в чат или журналы.
