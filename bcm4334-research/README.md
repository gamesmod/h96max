# BCM4334 / AP6334: regulatory-исследование и сборка bcmdhd

Материалы по Wi-Fi-чипу BCM4334/AP6334 и Android-драйверу bcmdhd для H96 Max на RK3318/RK3328. Дата среза — 2026-11-27; выводы, зависящие от конкретной firmware/NVRAM, помечены в документах как неподтверждённые до проверки на живом устройстве.

## Документы

- [Регуляторные возможности BCM4334](BCM4334_regulatory_report_ru.md) — таблица country codes в публичных CLM 1.6.5/1.21.1, путь Android, NVRAM, Bluetooth и read-only план проверки.
- [Сборка bcmdhd для кастомных прошивок](BUILDING_BCMDHD_RU.md) — флаги `CONFIG_AP6XXX`, кросс-компиляция, firmware/NVRAM/CLM, установка и диагностика.
- [Рабочие заметки](notes.md) — первичные источники и промежуточные наблюдения.

## Артефакты

- `src/` — выбранные исходники Rockchip bcmdhd, AOSP Wi-Fi/Bluetooth и документация Infineon WHD.
- `fw/` — публичные firmware, NVRAM, CLM-совместимые файлы и Bluetooth HCD; бинарники хранятся через Git LFS.
- `*_tree.json` — снимки дерева публичных репозиториев, использованные при сборе материалов.

Инструкция по сборке не является средством обхода регуляторных ограничений: country code должен соответствовать юрисдикции эксплуатации, а `ALL` и чужие коды не используются как замена национальному режиму.
