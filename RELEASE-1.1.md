# Выпуск 1.1 — установка на внутреннюю память (2026-10-27)

Файлы: `release/1.1/sd` (образ SD, 17 регионов, с разделом tvbox_emmc), `release/1.1/emmc` (образ для внутренней памяти, без плитки «Установка»). Суммы — SHA256SUMS в каждой папке.

## Новое относительно 1.0

- **Установка** (org.tvbox.installer, только на SD): состояние, установить на внутреннюю память, проверить, резервная копия eMMC на SD, восстановить, журнал. Опасные действия — двойное подтверждение.
- **tvboxd** — системная служба (app_process, root, init): выполняет команды установщика через абстрактный сокет, принимает только приложение «Установка» (и root/adb). Запись eMMC только при загрузке с SD, сверка md5 образа до и после записи, force_ro возвращается всегда. Раз в сутки обновляет базы Hypatia (подпись GPG проверяет Hypatia).
- **Раздел tvbox_emmc** на SD (2 ГиБ, после super): eMMC-образ для установщика; userdata — раздел 16.
- **Ссылки** (org.tvbox.links): QR-коды работающих веб-служб (TorrServer :8090, удалённый доступ VLC :8080).
- **Hypatia** (форк MaintainTeam 3.18) — антивирус, запуск вручную.
- 14 плиток по умолчанию; красный значок «Питание»; удалены SkySetupWizard, MediaCenter, glmark2; удалён адрес вендорского OTA.

## Проверено

- Сборки SD и eMMC без ошибок; в eMMC-образе нет «Установки», есть tvboxd; адреса OTA нет.
- tvboxd вживую: STATUS (eMMC = стоковый Android 9), HYPATIA_UPDATE (7 файлов, подпись проверена Hypatia).
- «Установка» и «Ссылки» на экране работают.

## Не проверено

- Установка на eMMC (INSTALL) — первый запуск вместе с пользователем.
- SD-образ 1.1 ещё не записан на карту (на карте 1.0 + вживую tvboxd, «Установка», «Ссылки», Hypatia).
