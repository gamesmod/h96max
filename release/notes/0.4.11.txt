# Panadonik 0.4.11 — новый кандидат после 0.4.10

## Изменения

- Версия поднята до 0.4.11: GitHub prerelease `dev-v0.4.10` уже опубликован; каталог
  `release/0.4.10` и установленный артефакт 0.4.10 сохранены без удаления.
- Цель кандидата — повторная сборка подписанного OTA/eMMC на каноническом хосте hpprobuntu
  с актуальным `origin/master` (включая архитектурную схему draw.io и последующие коммиты
  после содержимого OTA 0.4.10).
- Состав и поведение по отношению к 0.4.10 без отдельных функциональных изменений в этой
  подготовке версии: новый номер нужен, чтобы не переиспользовать уже выпущенный тег.

## Ограничения

Это описание кандидата. Публикация тега/GitHub Release, установка на приставку и очистка
данных не входят в эту сборку и требуют отдельных подтверждений пользователя. Аппаратные
пробелы 0.4.10 (QR TorrServer → «Смотреть на ТВ», USB-пульт/PAGE, полный network capture,
security_review) остаются открытыми до новой приёмки именно этого артефакта 0.4.11.
