# Panadonik 0.4.5 — dev-кандидат

## Изменения

- IPTV теперь передаёт VLC плейлист выбранной категории, начиная с выбранного канала. Это даёт VLC очередь соседних каналов для переключения во время просмотра.
- Для итогового IPTV-плейлиста ещё не пройден релизный gate: сейчас категория «Для взрослых» не первая и проверка видит 0 каналов 18+ вместо требуемых 20. Список обновляет отдельная сессия; этот кандидат нельзя считать готовым для публикации или использования как итоговый IPTV-набор.
- Обновлены собственные APK и системный образ на базе Android 12 для H96 Max / RK3328.

## Важно перед установкой

Это dev-кандидат, аппаратная приёмка не завершена. Текущий пакет OTA устанавливается только с очисткой пользовательских данных: будут удалены приложения, настройки, торренты и пользовательские файлы. До установки сделайте резервную копию и отдельно подтвердите операцию в интерфейсе.

Не завершены аппаратная проверка кнопок PAGE вверх/вниз комплектного USB-пульта, полный прогон сети, QR, торрентов и графики, а также контролируемый анализ сетевого трафика. В собранной конфигурации отмечен открытый риск `SELinux permissive`. Не считать этот кандидат стабильным выпуском.
