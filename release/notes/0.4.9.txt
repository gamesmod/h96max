# Panadonik 0.4.9 — встроенный файловый менеджер «Файлы»

## Изменения

- Total Commander и его плагины LAN/FTP/SFTP исключены из образа, из списка обязательных APK и из источников Obtainium.
  При первой загрузке после обновления они удаляются с приставки вместе со своими записями в Obtainium.
- Новая плитка «Файлы» (`org.tvbox.files`) — встроенный файловый менеджер по умолчанию. Она стоит на главном
  экране третьей, после TorrServe, и занимает место прежней плитки Total Commander без сброса порядка пользователя.
- «Файлы» работают с правами root: просмотр любых папок, копирование, перемещение, переименование, удаление и
  создание папок выполняет служба `tvboxd` (команды `FS_*`), доступные только этому приложению, root и shell.
  Приложение не вызывает `su`; ограничение `su` до root и группы shell сохраняется.
- Файлы открываются в VLC и других приложениях через собственный провайдер только для чтения; «Файлы» также
  открывают папки по запросу других приложений и позволяют выбрать файл (`GET_CONTENT`).
- Версия поднята до 0.4.9.

## Ограничения

Это описание кандидата. Работа плитки «Файлы», передача файлов из системных папок в VLC и миграция плитки на
обновлённой приставке требуют аппаратной проверки перед публикацией.
