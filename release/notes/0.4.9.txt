# Panadonik 0.4.9 — штатный файловый менеджер и расширенный IPTV

## Изменения

- Total Commander и его плагины LAN/FTP/SFTP исключены из образа, из списка обязательных APK и из источников Obtainium.
  При первой загрузке после обновления они удаляются с приставки вместе со своими записями в Obtainium.
- Файловый менеджер по умолчанию — штатный «Файловый менеджер» Rockchip (RkExplorer, `com.android.rk`). Он остаётся
  в образе, стоит на главном экране третьей плиткой, после TorrServe, и занимает место прежней плитки Total Commander
  без сброса порядка пользователя. При первой загрузке он получает полный доступ к общей памяти и носителям.
- Штатный менеджер работает как системное приложение (uid system), а не от root: Android не запускает приложения
  от uid 0, а `su` для приложений закрыт (ограничение до root и группы shell сохраняется).
- Для папок, закрытых даже для системного приложения, в списке приложений есть запасной «Файлы (root)»
  (`org.tvbox.files`) без плитки: его операции выполняет служба `tvboxd` (команды `FS_*`, только для этого
  приложения, root и shell). Файлы открываются в VLC через собственный провайдер только для чтения.
- Версия поднята до 0.4.9.

## IPTV: расширен список источников

- Добавлены исходные списки потоков iptv-org по России, Беларуси, Казахстану, Украине, Узбекистану, Молдове,
  Армении, Грузии, Латвии и Эстонии. Они дают запасные адреса для русскоязычных каналов. Логотипы и категории
  берутся по tvg-id из публичного API iptv-org (новый параметр источника `meta=iptv-org` в `tools/iptv-merge.py`;
  растровые логотипы предпочитаются SVG, данные источника не перезаписываются).
- Добавлены бесплатный официальный плейлист Беларуси из Free-TV и категории iptv-org: сериалы, образ жизни,
  отдых на природе, образование, путешествия, юмор, классика, погода, релакс.
- Источник Nexonic IPTV отключён: плейлист отвечает HTTP 404.
- Пробная сборка только по новым источникам с компьютера сборки: 362 канала с подтверждённым 1080p, из них около
  145 отсутствовали в прежних источниках. Итоговое число каналов определяется сборкой выпуска после удаления дублей.

## Ограничения

Это описание кандидата. Плейлист с новыми источниками, работа плитки штатного файлового менеджера, «Файлы (root)», передача файлов из системных папок в VLC и миграция плитки на
обновлённой приставке требуют аппаратной проверки перед публикацией.
