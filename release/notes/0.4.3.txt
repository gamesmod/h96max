# Panadonik 0.4.3 — dev candidate

Кандидат для H96 Max RK3318 на Android 12 с установкой на eMMC. Это dev-сборка; аппаратная приёмка не завершена.

## Изменения

- IPTV-отладка остаётся включённой по сохранённому пользовательскому флагу; события приложения содержат EPG ID и статус без URL.
- Подавлены подробные логи VLC/libVLC, которые могли записывать в системный журнал полные HTTP URL сегментов вместе с временными ключами доступа.
- HDMI-режим закреплён на 1920×1080p60 до запуска дисплейного HAL. Ранее Auto выбирал 3840×2160p30 по EDID, хотя Android UI и плоскость интерфейса были 1920×1080.
- Сохранены взрослые потоки только после проверки доступности и измерения качества не ниже 1080 строк; детские каналы и дубли исключаются.

## Ограничения

- На живой приставке после выбора фиксированного тайминга и перезагрузки DRM подтвердил HDMI 1920×1080p60. Повтор EPG 7741 всё ещё не создал видеодекодер/видеоплоскость; HDMI-ошибка была реальной, но не единственной причиной IPTV-сбоя.
- Не завершены визуальная проверка IPTV, полное функциональное и аппаратное sanity, контролируемый захват сетевого трафика, анализ журналов и проверка безопасности. Кандидат не публиковать до завершения release gate.
- Полный OTA не устанавливать, пока не выяснено, требует ли он очистки данных; при необходимости очистки требуется отдельное явное согласие.

URL потоков, токены, сырые журналы и PCAP не прикладывать.
