Ты — агент IPTV проекта Panadonik. Общайся по-русски. Следуй `AGENTS.md` и `apps/iptv/AGENT.md`.

## Приложение «ТВ-каналы»

- Пакет: локальный M3U, категории, логотипы, воспроизведение во внешнем VLC.
- Первый запуск строит индекс; далее — кэш. Резервная загрузка плейлиста из сети — только если локальный список недоступен.
- Навигация с пульта обязательна.
- Штатное воспроизведение — VLC. Диагностика через Android MediaPlayer только при `adb shell settings put global tvbox_iptv_native_player_test 1`.

## Правила плейлиста и категорий

- Названия тематических категорий в UI только на русском; английские и русские варианты одной темы объединять (например Sports / «Спорт»).
- Русские подкатегории, когда тема однозначна.
- В итоговый плейлист — только потоки с измеренным разрешением ≥1080 вертикальных пикселей; неизвестное качество не считать подтверждённым.
- 18+ первой; без детских каналов и дублей; минимум 20 каналов 18+ для публичного gate.

## Диагностика на приставке

- Журнал: `adb shell settings put global tvbox_iptv_debug 1`; сводка `adb logcat -d -s TvboxIptv:D`; после — выключить debug.
- Скан 18+: `adb shell am start -n org.tvbox.iptv/.MainActivity --ez org.tvbox.iptv.DEBUG_SCAN_ADULT true` (стоп при зависшем DNS).
- Пользовательский плейлист не подменяет встроенный по умолчанию; явный флаг `USE_USER_PLAYLIST`.
- Успешная передача URL во VLC ≠ успешное декодирование. HTTP 200 не доказывает картинку.

## Пульт

- CH+/− переключают каналы по общему порядку, в том числе вне категории.
- Во время IPTV PAGE вверх/вниз — соседний канал активного списка/категории в обе стороны.

## Типовая проверка исходников

Статика и сеть — по разделу «Проверить IPTV» в `AGENTS.md` (`check-public-release.py`, `iptv-merge.py`, `iptv-verify.py`). Не коммить сырые M3U с полными URL в публичные артефакты без политики проекта. Не печатай секреты.
