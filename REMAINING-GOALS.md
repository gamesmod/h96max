## Приоритет

1. **Сценарий «Ссылки»:** QR на телефоне сразу открывает добавление торрента в TorrServer; после успеха — «Смотреть на ТВ» → VLC на приставке. Убрать QR VLC и веб-управление. В gate заменить `qr_vlc` на проверку этого сценария.
2. **Кандидат 0.4.11:** новая Actions-сборка подписанного OTA и clean-install из актуального commit (имеющийся локальный OTA предшествует изменениям исходников); сканер Wi-Fi credentials; совпадение встроенного IPTV M3U; без публикации до аппаратной приёмки и отдельного подтверждения пользователя.
3. **Аппаратная приёмка 0.4.11** на целевой плате (после согласия на очистку данных, если OTA её требует):
   - холодная загрузка до управляемого пульта рабочего стола;
   - USB ADB без экрана (автодоверие ещё не подтверждено) и Wi‑Fi у телевизора с автовосстановлением;
   - Bluetooth отдельно; регуляторный домен = фактическая страна;
   - IPTV ≥1080p, торрент-фильм без лагов, USB-пульт и PAGE± по каналам;
   - плитка FileExploresky (`com.droidlogic.FileBrower`), USB/SD; «Файлы (root)» при необходимости;
   - журналы + контролируемый сетевой захват; сырой PCAP не коммитить.
4. **Публикация через GitHub Actions:** четыре secrets подписи и актуальные входы из публичного Git LFS; кандидатный artifact → после gate и подтверждения — `dev-v*` / `v*` (тег не пушить без согласия). Источник `releases/latest` не выбирает prerelease.
5. **IPTV:** расширен входной каталог на 8 публичных списков Nexonic; измерения новых потоков не проведены, порог не подтверждён; история доступности global/device; на приставке — воспроизведение и категории на русском; ≥20 каналов 18+ первой группой для релизного списка.
6. **Пользовательские данные:** исходная раскладка плиток один раз; после OTA wipe — явный список удаляемого и согласие; автовосстановление Wi‑Fi без вшивания SSID в публичный образ.
7. **Документация выпуска:** README / `docs/install-from-stock.md` / черновик 4PDA сверить с реально проверенными функциями после gate.
8. **Аппаратные пределы:** без разгона выше штатных OPP; zRAM и дисковый swap не включать; историю производительности (7 дней) и CSV проверить на устройстве.
9. **Субтитры VLC** по умолчанию выключены (цель 10a в `GOALS.md`).

## Подтверждено на текущем этапе (не gate 0.4.11)

- Базовые функции 0.3.x–0.4.x (TorrServer, VLC, IPTV-плитка, пульт, CEC, тёмная тема) исторически работали; это не зачёт для 0.4.11.
- В исходниках: отказ `PERF_ZRAM_SET`, удаление стоковых APK по `tools/unused-stock-apps.txt`, штатный FM в `prebuilt/stock-filemanager/`, Obtainium только для стороннего ПО образа.
- CI `Repository CI` на отдельных коммитах проходил; актуальный успешный Actions candidate run для 0.4.11 не зафиксирован в QA.
- Протокол [`docs/release-qa/0.4.11.md`](docs/release-qa/0.4.11.md) / `.json` фиксирует локальную сборку, 159 тестов при повторной проверке исходников, успешную проверку подписи прежнего OTA и незакрытые dev/stable gate. Не переносить эти результаты на новый кандидат.

## Не делать без отдельного решения

- Публикационный тег, GitHub Release, установка OTA с wipe, force-push.
- Добавление в образ или цели ПО вне комплекта [`APPS.MD`](APPS.MD) / [`apps-sources.md`](apps-sources.md) / `tools/required-apps.sh`; включение zRAM на приставке.
- Объявление `security_review=pass` или аппаратного `pass` без свежих доказательств на том же SHA-256 артефакта.
