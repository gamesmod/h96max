# Оставшиеся цели проекта

Снимок состояния: 2026-11-06, firmware candidate пересобран из `39a5db0` после усиления проверки качества IPTV; аппаратная приёмка остаётся незавершённой. Файл разделяет проверенное, подготовленное и ещё не завершённое. Публикация/установка релиза остаётся пользовательской целью; известные критерии перед публикацией не следует объявлять пройденными без замера.

## Приоритетные незавершённые цели

1. **Довести выпуск 0.4.0 до универсального сценария установки и обновления.** Подготовить один релизный набор с подписанным OTA для уже установленной системы и полным комплектом eMMC для чистой установки со стока через Rockchip Loader. В меню «Установка» показывать описание конкретного выпуска. Проверить оба пути на железе и сохранить прежние ключи подписи. Не выпускать отдельный образ для SD; установка/загрузка с SD остаётся штатной возможностью Android 12. Установка OTA сейчас требует очистки данных; не ставить без явного подтверждения пользователя.
2. **Закончить интеграцию Алисы.** RuStore разрешён только как временный источник APK; сам магазин не включать в образ, плитки, Obtainium и пользовательские инструкции. Выбрать официальную карточку RuStore разработчика Яндекс, проверить подпись APK, поставить Алису, назначить помощником, выдать доступ к микрофону и проверить кнопку USB-пульта и голосовой ответ. Устройство Android 12 поддерживает пакет `com.yandex.aliceapp` (RuStore указывает минимум Android 9). На приставке Алиса ещё не установлена; RuStore отсутствует.
3. **Верификация IPTV с историей.** В `tools/iptv-verify.py` реализованы JSONL-история без потоковых URL, отдельные области `global`/`device`, рейтинг за 30 дней и исключение после трёх неудач с интервалом минимум 24 часа; успех сбрасывает серию. Юнит-тесты проверяют эти правила. Сборщик проверяет глобальный поток и разрешение; первый глобальный прогон записан локально 2026-11-06: 2990 OK, 17 одиночных таймаутов оставлены; JSONL без URL содержит 3007 записей. Запуск verifier на самой приставке пока недоступен (нет Python/curl/wget), отчёты device-scope ещё не накоплены.
4. **Собрать и проверить публичный релиз в GitHub Actions.** GitHub API на 2026-11-06 показывает 0 releases, 0 Actions runs и 0 тегов. Локальный eMMC OTA 0.4.0 пересобран с hardening-правками и подписан прежним ключом; аппаратная приёмка не пройдена. Release должен содержать OTA, `latest-emmc.txt`, суммы, APK, полный комплект чистой установки, протокол аппаратной приёмки, автоматические тесты и анализ журналов. Добавлен CI-тестовый gate. Секреты URL/SHA закрытых входных файлов и прежние ключи Actions не проверялись.
5. **Проверить приложения и функции на целевой приставке после установки/обновления.** QR TorrServer/VLC, кнопку запуска VLC, Obtainium в плитке «Установка», IPTV, сеть, торрент-фильм/трансляцию и графический тест; записать результаты. Запуск Total Commander из QR-модуля и плагин WiFi Transfer исключены из целей по решению пользователя; плагин удалён с приставки. Проверенный плейлист требует измеренное качество не ниже 1080p, объединяет переведённые темы на русском и использует подкатегории для распознанных дисциплин. На установленной 0.3.9 остаётся предыдущий проверенный override: 3008 каналов, 59 M3U-категорий, 53 отображаемые группы, 184 канала 18+ первыми; новый строгий список на приставку не передан из-за потери ADB. Для локального кандидата заново измерено 3007 потоков через `ffprobe`, включая 184 канала 18+, 58 M3U-групп, все категории русские, дубликатов и неподтверждённого разрешения нет. Последний глобальный повторный прогон подтвердил 2990, 17 каналов временно не ответили (одна неудача, не исключены); успешные потоки от 1080 строк. Новый список ещё не проверен в UI приставки. Full HD видеокадр и отсутствие лагов не подтверждены; торренты и графику ещё предстоит проверить. Алиса не установлена, RuStore отсутствует.
6. **Достичь холодной загрузки ≤10 секунд от подключения питания.** Известный замер перезагрузки около 75 секунд; холодный старт секундомером не замерялся. Цель не достигнута.
7. **Dev-релиз: стабильность и функциональность.** Dev-релиз может содержать раскрытые известные риски, но каждый выпуск обязан пройти анализ журналов и сетевого захвата; ежемесячный workflow контролирует свежесть отчёта в пределах 31 дня. Обязательны автотесты, функциональный gate и разбор ошибок, влияющих на воспроизведение/отзывчивость. Текущая приставка 0.3.9 всё ещё имеет root ADB на TCP 5555 и SELinux Permissive; в финальном кандидате включён `ro.debuggable=1` и `androidboot.selinux=permissive`, поэтому security review остаётся fail. Актуальная выборка logcat: 3 служебных Broadcom scan-ID, 1 воспроизводимая EGL ошибка Obtainium, 768 предупреждений, включая 751 повтор FunctionFS за 13 минут. Obtainium UI отрисовался, но видео/графическая плавность ещё не проверена. Сырые журналы/PCAP не публиковать.
8. **Проверить пользовательские данные на чистой установке и после OTA.** Исходная раскладка плиток должна применяться один раз, затем пользовательский порядок сохраняется; игры исключены из продукта заранее. Проверить первичные разрешения, журнал производительности и CSV-экспорт.
9. **Описать процедуру установки и подготовить короткий пост для 4PDA.** README должен давать безопасную пошаговую установку со стока и способы обновления универсального выпуска; создать отдельную короткую публикацию с преимуществами, отличиями от базового образа и реально работающими функциями.
10. **Сохранить аппаратные ограничения.** Не разгонять выше штатных OPP без охлаждения и повторяемого стресс-теста: установленный предел CPU 1,104 ГГц/GPU 400 МГц, краткая нагрузка нагрела SoC примерно до 81,5 °C. История производительности ограничена 7 днями; требуется проверить её отображение в виджете и экспорт.
