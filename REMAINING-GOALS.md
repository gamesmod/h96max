# Оставшиеся цели проекта

Снимок состояния: 2026-11-06, коммит `7b227ae` плюс текущая финальная пересборка. Файл разделяет проверенное, подготовленное и ещё не завершённое. Публикация/установка релиза остаётся пользовательской целью; известные критерии перед публикацией не следует объявлять пройденными без замера.

## Приоритетные незавершённые цели

1. **Довести выпуск 0.4.0 до универсального сценария установки и обновления.** Подготовить один релизный набор с подписанным OTA для уже установленной системы и полным комплектом eMMC для чистой установки со стока через Rockchip Loader. В меню «Установка» показывать описание конкретного выпуска. Проверить оба пути на железе и сохранить прежние ключи подписи. Не выпускать отдельный образ для SD; установка/загрузка с SD остаётся штатной возможностью Android 12. Установка OTA сейчас требует очистки данных; не ставить без явного подтверждения пользователя.
2. **Закончить интеграцию Алисы.** RuStore разрешён только как временный источник APK; сам магазин не включать в образ, плитки, Obtainium и пользовательские инструкции. Выбрать официальную карточку RuStore разработчика Яндекс, проверить подпись APK, поставить Алису, назначить помощником, выдать доступ к микрофону и проверить кнопку USB-пульта и голосовой ответ. Устройство Android 12 поддерживает пакет `com.yandex.aliceapp` (RuStore указывает минимум Android 9). На приставке Алиса ещё не установлена; RuStore отсутствует.
3. **Верификация IPTV с историей.** В `tools/iptv-verify.py` реализованы JSONL-история без потоковых URL, отдельные области `global`/`device`, рейтинг за 30 дней и исключение после трёх неудач с интервалом минимум 24 часа; успех сбрасывает серию. Юнит-тесты проверяют эти правила. Сборщик проверяет глобальный поток и разрешение; запуск verifier на самой приставке пока недоступен (нет Python/curl/wget), отчёты device-scope ещё не накоплены.
4. **Собрать и проверить публичный релиз в GitHub Actions.** GitHub API и `git ls-remote --tags origin` не показывают релизов/тегов. Локальный eMMC OTA 0.4.0 пересобран с hardening-правками и подписан прежним ключом; аппаратная приёмка не пройдена. Release должен содержать OTA, `latest-emmc.txt`, суммы, APK, полный комплект чистой установки, протокол аппаратной приёмки, автоматические тесты и анализ журналов. Добавлен CI-тестовый gate. Секреты URL/SHA закрытых входных файлов и прежние ключи Actions не проверялись.
5. **Проверить приложения и функции на целевой приставке после установки/обновления.** QR TorrServer/VLC, кнопку запуска VLC, Obtainium в плитке «Установка», IPTV, сеть, торрент-фильм/трансляцию и графический тест; записать результаты. Запуск Total Commander из QR-модуля и плагин WiFi Transfer исключены из целей по решению пользователя; плагин удалён с приставки. Новый список 1080p+ проверен на живой 0.3.9: 3008 уникальных URL, 184 канала 18+ первыми, 48 отображаемых групп, детские группы и дубли отсутствуют; повторно подтвердились 2992 потока, 16 после краткого таймаута оставлены по предыдущему успеху; индексирование заняло 103,5 секунды. Full HD запуск VLC даёт активную медиасессию, но ADB screenshot чёрный, поэтому визуальное IPTV-воспроизведение остаётся pending. Проверить QR VLC, сеть, торренты и графику ещё предстоит. Алиса не установлена, RuStore отсутствует.
6. **Достичь холодной загрузки ≤10 секунд от подключения питания.** Известный замер перезагрузки около 75 секунд; холодный старт секундомером не замерялся. Цель не достигнута.
7. **Dev-релиз: стабильность и функциональность.** Не блокировать dev-релиз закрытием security review; подтверждённые риски зафиксировать в prerelease notes. Обязательны автотесты, функциональный gate и разбор ошибок, влияющих на воспроизведение/отзывчивость. Текущая приставка 0.3.9 всё ещё имеет root ADB на TCP 5555 и SELinux Permissive; эти вопросы оставить в отдельном security backlog для стабильного выпуска. Свежая выборка logcat содержит VLC/MediaCodec, Fontconfig, NativeWindow/FrameEvents/Codec2, deadlock и dropped audio; нужно воспроизвести и оценить влияние. В финальном кандидате включён `ro.debuggable=1` и `androidboot.selinux=permissive`, поэтому security review остаётся fail. Сырые журналы/PCAP не публиковать.
8. **Проверить пользовательские данные на чистой установке и после OTA.** Исходная раскладка плиток должна применяться один раз, затем пользовательский порядок сохраняется; игры исключены из продукта заранее. Проверить первичные разрешения, журнал производительности и CSV-экспорт.
9. **Описать процедуру установки и подготовить короткий пост для 4PDA.** README должен давать безопасную пошаговую установку со стока и способы обновления универсального выпуска; создать отдельную короткую публикацию с преимуществами, отличиями от базового образа и реально работающими функциями.
10. **Сохранить аппаратные ограничения.** Не разгонять выше штатных OPP без охлаждения и повторяемого стресс-теста: установленный предел CPU 1,104 ГГц/GPU 400 МГц, краткая нагрузка нагрела SoC примерно до 81,5 °C. История производительности ограничена 7 днями; требуется проверить её отображение в виджете и экспорт.

## Подтверждено на текущем этапе

- Свежая полная сборка eMMC 0.4.0 выполнена после фикса границ чтения OTA-helper. Финальный build log: 134 строки, ноль предупреждений/ошибок; helper отдельно прошёл компиляцию `-Wall -Wextra -Werror`. OTA SHA-256 `715a1ee6280ef4fb0880837614eb54d138489c08bd3ddf18700de70be3ee5854`; clean-install пакет SHA-256 `87ed2fe047f0f84abd2b088fbe311a2754632e8d2e35af0d183be838714d5243`. Обе ZIP целы и подписаны прежним сертификатом. Артефакты находятся в игнорируемом `release/` и не опубликованы.
- В workflow добавлены сборка OTA, APK Panadonik, `latest-emmc.txt`, SHA256SUMS, автоматические тесты, анализ журнала сборки и комплект чистой установки. Локальный `Panadonik-0.4.0-emmc-clean-install.zip` собран и SHA-256 проверен; аппаратный путь через Loader не проверен.
- Метаданные релиза передаются в меню обновления через `latest-emmc.txt`; проверить отображение на приставке после настоящего обновления ещё нужно.
- `tools/iptv-merge.py` собирает категории в один общий плейлист, нормализует подписи на русский, ставит категорию 18+ первой, отмечает распознанные регионы флагом страны и схлопывает дубли/варианты качества. История в `tools/iptv-verify.py` реализована: JSONL без URL, области global/device, рейтинг за 30 дней, удаление только после трёх отказов с интервалом 24 часа. Реальных device-scope наблюдений пока нет.
- Игры исключаются при сборке образа; удаление при первом старте оставлено для старых/пользовательских копий.
- Obtainium размещён внутри плитки «Установка». Отдельная плитка Obtainium не нужна. Отдельные плитки VLC и антивируса не выводятся.
- Аппаратная заметка о Wi-Fi/BT, базовом A12 образе и ревизии платы внесена в начало README; проверять эти настройки на иной аппаратной ревизии нельзя без осмотра.
- Дисковый swap выключен и навсегда запрещён. Не создавать swap-файл или раздел и не включать zRAM writeback на накопитель. Wi-Fi credentials и подписи/ключи в Git/публичный релиз не помещать.

## Рабочее дерево на момент снимка

Ветка `master` на удалённом `origin` указывает на `7b227ae`; тегов и GitHub Releases нет. Свежая финальная локальная сборка 0.4.0 находится в игнорируемом `release/`; артефакты подписаны прежним OTA сертификатом и не опубликованы. 24 автотеста проходят, build log — 0 ошибок/предупреждений. Прямые hot-checks: IPTV и Links APK запускаются, Wi-Fi проверен, RuStore удалён; VLC remote недоступен, Ethernet без carrier, остальная функциональная матрица не закрыта. Dev gate не пройден. OTA очищает пользовательские данные, установка ожидает отдельного явного подтверждения.
