# Оставшиеся цели проекта

Снимок состояния: 2026-11-06. Файл разделяет проверенное, подготовленное и ещё не завершённое. Публикация/установка релиза остаётся пользовательской целью; известные критерии перед публикацией не следует объявлять пройденными без замера.

## Приоритетные незавершённые цели

1. **Довести выпуск 0.4.0 до универсального сценария установки и обновления.** Подготовить один релизный набор с подписанным OTA для уже установленной системы и полным комплектом eMMC для чистой установки со стока через Rockchip Loader. В меню «Установка» показывать описание конкретного выпуска. Проверить оба пути на железе и сохранить прежние ключи подписи. Не выпускать отдельный образ для SD; установка/загрузка с SD остаётся штатной возможностью Android 12. Установка OTA сейчас требует очистки данных; не ставить без явного подтверждения пользователя.
2. **Закончить Алису без RuStore.** RuStore не включать в образ, плитки, Obtainium и пользовательские инструкции. Найти официальный способ установки Алисы отдельным APK/официальным каталогом, проверить подпись, поставить на приставку, назначить помощником, выдать разрешение микрофона и проверить кнопку USB-пульта и ответ голосом. Сейчас пакет Алисы на приставке не подтверждён; установленный ранее RuStore TV уже удалён с устройства. Не подменять официальный источник случайным APK-сайтом.
3. **Верификация IPTV с историей.** При каждой проверке читать предыдущие результаты; записывать проверки с датой и областью (`глобальная`, `приставка`). Сверять доступность извне и, по возможности, с работающей приставки. Не выкидывать канал после единичного сбоя: исключать только после устойчивого отсутствия, определённого по нескольким разнесённым проверкам. Историю хранить без полных URL/секретных токенов; в итоговом плейлисте оставить все категории вместе, исключая дубли каналов и качества. На горячей приставке сейчас не обнаружены `curl`, `wget` и `python3`, поэтому для реальной проверки с устройства нужен безопасный встроенный помощник или отчёт из приложения.
4. **Собрать и проверить публичный релиз в GitHub Actions.** GitHub API и `git ls-remote --tags origin` не показывают релизов/тегов. Локальный eMMC OTA 0.4.0 пересобран с hardening-правками и подписан прежним ключом; аппаратная приёмка не пройдена. Release должен содержать OTA, `latest-emmc.txt`, суммы, APK, полный комплект чистой установки, протокол аппаратной приёмки, автоматические тесты и анализ журналов. Добавлен CI-тестовый gate. Секреты URL/SHA закрытых входных файлов и прежние ключи Actions не проверялись.
5. **Проверить Алису и приложения на целевой приставке после установки/обновления.** QR-ссылки с запуском VLC и Total Commander, Obtainium в плитке «Установка», IPTV, сеть, торрент-фильм/трансляция и графический тест; записать результаты. Проверить, что RuStore не установлен. На текущей 0.3.9 запущен IPTV и подтверждён просмотр Sochi24 (720p) во VLC около 20 секунд; графику без пропусков кадров, QR и торрент в этой сессии не проверяли. Пакет Алисы не установлен.
6. **Достичь холодной загрузки ≤10 секунд от подключения питания.** Известный замер перезагрузки около 75 секунд; холодный старт секундомером не замерялся. Цель не достигнута.
7. **Завершить релизную проверку безопасности и журналов.** На каждый выпуск запускать тесты, анализировать логи, триажить каждую ошибку и прикладывать отчёт. В текущем анализе остаются повторяющиеся USB gadget/FunctionFS, графические и vendor-ошибки. Горячая проверка 0.3.9 подтвердила root ADB на всех интерфейсах TCP 5555 без авторизации, `su` 6755 для всех приложений и SELinux Permissive. В кандидате 0.4.0 исправлено расположение свойств `ro.secure=1`/`ro.adb.secure=1`, убран старт TCP ADB, `su` ограничен до 4750 root:shell; разделы собранного кандидата проверены статически, но на приставке не установлены. SELinux и TorrServer :8090 остаются открытыми рисками. Захват IPTV-трафика показал HTTP без найденных auth/cookie/token; сырые журналы/PCAP не публиковать. CSI-сообщений в доступной выборке не обнаружено.
8. **Проверить пользовательские данные на чистой установке и после OTA.** Исходная раскладка плиток должна применяться один раз, затем пользовательский порядок сохраняется; игры исключены из продукта заранее. Проверить первичные разрешения, журнал производительности и CSV-экспорт.
9. **Описать процедуру установки и подготовить короткий пост для 4PDA.** README должен давать безопасную пошаговую установку со стока и способы обновления универсального выпуска; создать отдельную короткую публикацию с преимуществами, отличиями от базового образа и реально работающими функциями.
10. **Сохранить аппаратные ограничения.** Не разгонять выше штатных OPP без охлаждения и повторяемого стресс-теста: установленный предел CPU 1,104 ГГц/GPU 400 МГц, краткая нагрузка нагрела SoC примерно до 81,5 °C. История производительности ограничена 7 днями; требуется проверить её отображение в виджете и экспорт.

## Подтверждено на текущем этапе

- Локальная полная сборка eMMC 0.4.0 завершилась успешно после hardening-правок; CMS-подпись и SHA-256 проверены. В предупреждении компилятора `ota/tvbox-flash.c` на строке readback задан предел чтения до размера буфера; предупреждение требует включения в анализ сборочных логов. Артефакты находятся в игнорируемом `release/` и не опубликованы.
- В workflow добавлены сборка OTA, APK Panadonik, `latest-emmc.txt`, SHA256SUMS, автоматические тесты, анализ журнала сборки и комплект чистой установки. Локальный `Panadonik-0.4.0-emmc-clean-install.zip` собран и SHA-256 проверен; аппаратный путь через Loader не проверен.
- Метаданные релиза передаются в меню обновления через `latest-emmc.txt`; проверить отображение на приставке после настоящего обновления ещё нужно.
- `tools/iptv-merge.py` собирает категории в один общий плейлист, нормализует подписи на русский, ставит категорию 18+ первой, отмечает распознанные регионы флагом страны и схлопывает дубли/варианты качества. Устойчивость канала по истории прошлых проверок в `tools/iptv-verify.py` ещё не реализована.
- Игры исключаются при сборке образа; удаление при первом старте оставлено для старых/пользовательских копий.
- Obtainium размещён внутри плитки «Установка». Отдельная плитка Obtainium не нужна. Отдельные плитки VLC и антивируса не выводятся.
- Аппаратная заметка о Wi-Fi/BT, базовом A12 образе и ревизии платы внесена в начало README; проверять эти настройки на иной аппаратной ревизии нельзя без осмотра.
- Дисковый swap выключен и навсегда запрещён. Не создавать swap-файл или раздел и не включать zRAM writeback на накопитель. Wi-Fi credentials и подписи/ключи в Git/публичный релиз не помещать.
