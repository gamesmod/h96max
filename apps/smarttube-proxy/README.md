# SmartTube Proxy Manager — автономный прокси для Panadonik

Компонент для Android 12: загрузка списков публичных прокси, проверка TLS и медиадиапазона, локальный шлюз 127.0.0.1:18765. Не требуется ROOT. Код не является принятым выпуском; сборка и эксплуатационная проверка пока не подтверждены.

## Запуск кандидата
1. Установить подписанный APK только после проверки SHA-256 и согласия на тестирование. Приложение отдельно от OTA.
2. Открыть «Прокси SmartTube», указать свежую медиассылку общедоступного тестового видео (HTTPS googlevideo.com/videoplayback), запустить.
3. После подтверждения WORKING/STABLE в SmartTube выбрать HTTP, хост 127.0.0.1, порт 18765, без логина и пароля, включить прокси. Проверить видео и отсутствие прямого обхода.
4. Откат: отключить прокси в SmartTube (или восстановить прежние настройки), остановить службу, удалить APK при необходимости.

Текущая версия требует ручной медиассылки; она может быть краткоживущей и привязана к IP. Поэтому полноценный автономный режим не реализован. Не используйте Google credentials через неизвестные прокси. Локальный шлюз доступен и другим приложениям на устройстве с INTERNET, ограничен списком доменов.

## Проверка на ПК
Python 3.10+, curl с SOCKS5 и современным ограничением объёма (8.4+).
`python3 proxy_check.py --sources-only`
`python3 proxy_check.py --media-url-file private-media.txt --limit 32`
Не коммитить файл с URL. На Windows использовать python вместо python3. Источники и зеркала в sources.json. Подробнее: PROXY_SOURCES.md, ARCHITECTURE.md, TESTING.md, SECURITY.md, TROUBLESHOOTING.md.

## Ограничения
IPv4 в Android; нет автономного получения URL, полной истории/blacklist, проверки страны, ручного выбора upstream, восстановления после reboot, настройки всех параметров, полноценного теста управления пультом. Отсутствует доказательство 1080p/4K, работы из РФ и полного покрытия сетевых клиентов SmartTube.
