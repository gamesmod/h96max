# Инструкции для агентов SmartTube Proxy Manager

Назначение: автономный компонент для Panadonik / H96 Max (Android 12), без обязательного сервера и ROOT. Соблюдать корневой AGENTS.md, правила подписи, аппаратной приёмки и релиза.

## Структура
- src/org/tvbox/smarttubeproxy/Gateway.java — локальный HTTP CONNECT, SOCKS5h и HTTP CONNECT upstream.
- SourceManager.java — получение списков, зеркала, локальный кеш, дедупликация.
- ProxyChecker.java — TLS, домены YouTube и реальные байты CDN.
- ProxyService.java — фоновые проверки, выбор, резерв и failover.
- MainActivity.java — TV UI; sources.json — расширяемая конфигурация.
- proxy_check.py, test_proxy_check.py — кроссплатформенная диагностика и тесты.
- build.sh — APK с общей версией Panadonik и существующим сертификатом.

Java 8 / Android SDK 32 / D8 / minSdk 24 / targetSdk 29 (проверить на целевой системе); Python 3.10+ и curl. Документация и UI по-русски; имена файлов и сущностей по-английски.

## Правила
- Не модифицировать SmartTube, его private prefs, системный прокси или tvboxd без отдельного подтверждённого обоснования.
- В источниках указывать HTTPS, формат, протокол, зеркала, период, лицензию; проверять реальное содержимое, не считать зеркала независимыми поставщиками. Не принимать частные IP, loopback, multicast, имена хостов из списков.
- TLS проверять стандартным trust store и hostname verification. Не логировать подписанные URL, cookies, токены, пароли, необработанный трафик и адреса в публичных отчётах. Только loopback, CONNECT к разрешённым доменам на 443; fail closed.
- Не присваивать WORKING/STABLE без подтверждённого медиадиапазона и достаточной скорости; тестировать повторно. HTTP ответ от корня API лишь подтверждает сетевой маршрут, не полноценную работу API.
- Не переключать здоровый upstream; новые туннели используют новый upstream, существующие не переносить. Ограничивать трафик, очереди, таймауты и число потоков. Запрещена дисковая подкачка/zRAM.
- TV: русский интерфейс, фокус и D-pad; проверить все экраны реальным пультом.
- Не публиковать неподтверждённые тесты. При изменении архитектуры актуализировать документацию, CHANGELOG и критерии приёмки.
- Команды: из каталога python3 -m unittest -v; python3 proxy_check.py --sources-only; bash build.sh (подготовленный SDK и прежние ключи); bash adb-diagnose.sh SERIAL. См. TESTING.md.
- Критерии: 5+ независимых источников из РФ; автоматическое получение действительной медиассылки; метрики и повторная проверка; failover, история, boot, ручной режим; полноценный D-pad; проверенный SmartTube на устройстве; успешная сборка, подпись и SHA-256, интеграционные тесты. Невыполненные критерии не скрывать.
- Выпуск: отдельный APK-кандидат, без добавления в образ до приёмки, без новых ключей, без автоматического тега/Release. Стабильный выпуск только по общему gate и подтверждению пользователя.
