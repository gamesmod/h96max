# Тестирование

Статус на 2026-11-24: исходники добавлены, автоматизированный прогон и сборка не подтверждены. Ни один аппаратный или российский сетевой тест не объявлять PASS.

- Python: python3 -m unittest -v (парсинг, дедупликация, специальные адреса, JSON, медиассылка, статус).
- Сборка: JDK 17+ / Android SDK platform 32 / build-tools 35.0.0 / существующие ключи проекта; bash build.sh. Проверить APK, подпись, SHA256SUMS.
- Живая сеть: python3 proxy_check.py --sources-only; затем --media-url-file с действительным публичным тестовым видео. Сохранить только агрегированные результаты с датой/сетью/коммитом.
- H96 Max: adb-diagnose.sh SERIAL, проверить Android 12, ABI, фактическое приложение и loopback. Дальше проверить D-pad, SmartTube с видео, отказ upstream, смену резерва, восстановление сети и перезагрузку. Измерить длительное воспроизведение, а не только 256 KiB тест.
- Необходимы интеграционные тесты реального CONNECT/SOCKS5, failover, boot и ограничений безопасности. CI не является тестом из РФ.
