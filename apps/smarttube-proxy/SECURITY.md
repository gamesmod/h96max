# Безопасность

Публичный прокси может быть вредоносным, видеть домены/метаданные и отказывать в обслуживании. Не использовать Google credentials; TLS и hostname verification обязательны. Не устанавливать CA и не перехватывать TLS. Не коммитить подписанные ссылки, сырые журналы, ключи, PCAP.

Встроенный шлюз Panadonik Tube слушает случайный порт только на `127.0.0.1`, принимает CONNECT лишь к разрешённым YouTube/Googlevideo-доменам на 443 и требует случайный process-local токен в `Proxy-Authorization`. Токен не пишется на диск и в журналы. При отсутствии валидного upstream шлюз делает прямой CONNECT, чтобы не блокировать приложение; домены вне allowlist всегда обходят шлюз. Это аварийная доступность, а не доказательство приватности.

Нужен аудит фактического трафика, невозможности обхода выбранного маршрута, лимитов и поведения OAuth. Source config является доверенным входом сборки; пользовательские allow/deny/manual-файлы остаются private app data. Не считать код прошедшим security review до проверки на устройстве. Откат: отключить «Автопрокси Panadonik» в сетевых настройках SmartTube; глобальные настройки Android не меняются.
