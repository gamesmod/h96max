# Безопасность

Публичный прокси может быть вредоносным, видеть домены/метаданные и отказывать в обслуживании. Не использовать Google credentials; TLS и hostname verification обязательны. Не устанавливать CA и не перехватывать TLS. Не коммитить подписанные ссылки, сырые журналы, ключи, PCAP. Шлюз слушает только 127.0.0.1, допускает CONNECT к разрешённым доменам YouTube/Googlevideo на 443, без прямого fallback; другие локальные приложения могут обратиться к порту. Нужен аудит фактического трафика и лимитов; source config доверенный локальный ввод. Не считать код прошедшим security review. Откат: отключить прокси в SmartTube, остановить службу, удалить APK.
