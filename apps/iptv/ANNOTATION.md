# Аннотация

**«ТВ-каналы»** — Android-приложение для просмотра IPTV на телевизионных приставках. Оно загружает список каналов из локального плейлиста M3U, группирует каналы по категориям, показывает логотипы и запускает воспроизведение во внешнем плеере VLC.

При первом запуске приложение подготавливает и сохраняет индекс плейлиста, а при последующих запусках использует кэш. Если локальный список недоступен, предусмотрена загрузка резервного плейлиста из сети. Интерфейс поддерживает навигацию с пульта дистанционного управления. Диагностический путь через Android MediaPlayer включается только для сравнения командой `adb shell settings put global tvbox_iptv_native_player_test 1`; штатное воспроизведение передаётся VLC.

Проект содержит исходный код приложения, ресурсы интерфейса, Android-манифест и сценарий сборки APK. Для работы требуются Android 6.0 или новее, доступ к плейлисту и установленный VLC.

## Диагностика воспроизведения

Отладочный журнал по умолчанию выключен. На приставке включите его командой `adb shell settings put global tvbox_iptv_debug 1`. При выборе канала приложение пишет только безопасные события с EPG ID и схемой URL; выбранный поток автоматически не проверяется HTTP-запросом. Для последовательной проверки всей категории 18+ используйте `adb shell am start -n org.tvbox.iptv/.MainActivity --ez org.tvbox.iptv.DEBUG_SCAN_ADULT true`; скан останавливается при зависшем DNS. Снять сводку: `adb logcat -d -s TvboxIptv:D`; после диагностики выключить `adb shell settings put global tvbox_iptv_debug 0`.

Пользовательский плейлист не подменяет встроенный по умолчанию. Явно включить его: `adb shell am start -n org.tvbox.iptv/.MainActivity --ez org.tvbox.iptv.USE_USER_PLAYLIST true`; выключить: та же команда с `false`.

Успешная передача URL во VLC подтверждает только запуск внешнего плеера, а не декодирование. Код HTTP помогает отличить отказ источника (например, 401/403/404) от ошибки формата или кодека; статус 200 сам по себе не доказывает успешное видео. Если VLC получает успешный HTTP-ответ, но не показывает видео, для точной причины потребуется журнал VLC с приставки.
