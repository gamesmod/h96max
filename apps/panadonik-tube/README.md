# Panadonik Tube — сборка из исходников

База: SmartTube-CN 32.63-cn-20261008-r101, точный Git SHA и вариант в `source.lock.json`. Используется F-Droid release flavor; готовые APK SmartTube не скачиваются. Исходники и submodules берутся из зафиксированного дерева Git. Патчи применяются только при совпадении контекста, без best-effort. Два APK: ARMv7 и ARM64.

## Профиль H96 Max
- Собственный package ID org.tvbox.panadoniktube и search provider; не перезаписывать SmartTube.
- Не строить stable/beta, x86, universal; локализации RU/EN и базовые ресурсы.
- Исключить Google Services и Crashlytics Gradle plugins; выбранный F-Droid flavor не включает beta/stable Crashlytics dependencies. Дополнительная проверка APK обязательна; это не полный аудит телеметрии.
- Отключить встроенный механизм обновлений, автопрокрутку названий карточек по умолчанию; upstream уже отключает previews и UI-анимацию по умолчанию.
- При выборе HTTP 127.0.0.1:18765 в SmartTube принудительно использовать OkHttp с явным локальным proxy для media factory. Не менять глобальные настройки Android, не отключать TLS.
- Не удалять MediaCodec, DASH, SABR, HLS, нативные декодеры, leanback/voice/субтитры до теста зависимостей. R8 и дальнейшее удаление библиотек — отдельная измеряемая оптимизация; не обещать размер или ускорение без теста.

## Сборка
JDK 17, SDK API 34, Build Tools 30.0.3, NDK 21.0.6113669, Git, Python 3.
`python3 -m unittest -v` затем `bash build.sh` (из этого каталога). Release-контур после source build выполняет `bash sign.sh`; ключи используются только локальным шагом подписи и не передаются upstream Gradle.
Выход: `out/PanadonikTube-*-unsigned.apk`, checksums, submodule revisions, основной и SharedModules patch, лицензия и source lock. Не устанавливать неподписанный кандидат.

## Статус
Кандидат сборочной интеграции, не часть прошивки до приёмки. Автономная проверка медиабайтов на каждом резервном прокси ещё не реализована; автоматическое переключение и сброс кеша при буферизации добавлены в .2. Не передавать пользовательские signed media URLs в сторонние приложения/логи. Использовать публичное тестовое видео и изолированную диагностику без Google credentials. Сеть РФ, реальный H96 Max, скорость и размер не подтверждены.

## Автоматический прокси

Встроен в процесс Panadonik Tube, отдельный APK не нужен. Активны шесть независимо обрабатываемых адаптеров форматов TXT, JSON, CSV, HTML и Geonode JSON. При менее пяти непустых источниках первичная проверка остаётся незавершённой и повторяется. Поддерживаются IPv4 HTTP/HTTPS CONNECT, SOCKS4a и SOCKS5h; приватные, loopback, multicast и служебные диапазоны отвергаются. Каждый источник ограничен 128 кандидатами, после нормализации проверяется весь объединённый набор. Прогресс хранится в private SharedPreferences; прерванная первичная проверка безопасно повторяется.

Локальный шлюз слушает случайный порт только на `127.0.0.1` и требует случайный process-local токен, который не сохраняется и не логируется. ProxySelector направляет только allowlist YouTube API/CDN, остальные домены идут напрямую. При пустом пуле шлюз также использует прямое соединение, поэтому запуск не блокируется. Ротация применяется к новым соединениям при деградации; TLS не перехватывается. В настройках сети доступны автопрокси, ротация, обновление/статус и штатный ручной HTTP/SOCKS proxy.

Локальные private-файлы `manual-proxies.txt`, `proxy-allowlist.txt` и `proxy-denylist.txt` принимают по одной записи `protocol://ip:port` на строку. Пароли из публичных источников не принимаются.

Открытые прокси не обеспечивают приватность: оператор может журналировать домены, блокировать соединения, подменять незашифрованный трафик либо использовать узел как honeypot. Не входить через них в Google, не выполнять платежи и не устанавливать пользовательские CA. Авторизация и домены вне YouTube allowlist идут напрямую. Российская сеть, реальные медиабайты, длительное воспроизведение и H96 Max остаются обязательным аппаратным gate.

## Критерии приёмки
- Сборка, ABI/package/manifest и подпись.
- 1080p аппаратный декодер на H96 Max.
- Управление пультом (D-pad, OK, Back, голос).
- Локальный прокси для API/CDN, восстановление сети.
- Анализ памяти и кадров.
- Обновлять README при изменениях.
