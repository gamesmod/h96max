# Panadonik Tube
Сборка собственного Android TV клиента из исходников SmartTube. Работать по корневому AGENTS.md. Не заменять upstream APK и не загружать готовые сторонние APK для выпуска. Сохранить аппаратное декодирование, D-pad, DASH/SABR/HLS, TLS, архитектуры ARM. Версии фиксировать в source.lock.json; обновление — отдельная проверка diff, submodules, лицензий, зависимостей и контекста патчей. 
- python3 -m unittest -v
- bash build.sh (JDK 17, Android SDK 34, Build Tools 30.0.3, NDK 21.0.6113669, Git, Python 3)
- CI: .github/workflows/panadonik-tube.yml. Не передавать ключи подписи upstream Gradle. Кандидаты неподписанные, не устанавливать в систему; выпуск только после полного QA, отдельной подписи и разрешения.
