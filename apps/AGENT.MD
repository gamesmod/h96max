Выполняй компиляцию поставляеммых приложений для оптимизации производительности.
выполняй необходимые предварительные настройки:
 - русский язык, как язык по умолчанию для приложения
 - необходимые системные разрешения
 - настройка приложений по умолчанию
 - вид интерфейса: TV

## Документирование
Твоя задачи описывать все изменения связанные с установленным ПО
Разделяй на две категории, есть компоненты сторонних разработчиков, а есть собсвенные доработки:
    - Стороннее ПО: Этот список в табличном виде должен содержать информацию для вставки в Obtanium  и размещения на домашнем экране в лаунчере
    - Встроенно ПО: Этот список в табличном виде должен содержать информацию о функциональности и для достаточной для сборки при формирования релиза
При каждом изменении вноси информацию в APPS.MD
Добавь иконки в приложений в описание
Для каждой категории обязательный app_id и мета для проверки целостности бинарника
Для каждого приложения должен быть readme файл с описанием и нюансами, и указания для агента в части настроек.
